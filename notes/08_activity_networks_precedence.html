Graphing an Activity Network

An activity network is a directed graph where each vertex is a point in time, each directed edge is a task, and the weight of the edge is that task's duration — drawn from the precedence table above.

Activity network for the table above
Tip The edges (not the vertices) represent the tasks. The vertices are the points in time when tasks have been completed.

Dummy Activities

When the precedence table has a mismatch of predecessors, we sometimes need a dummy activity to make the activity network accurate. A dummy activity has no duration — it only shows a precedence relationship — and is drawn as a dashed line.

TaskDurationPredecessors
A2—
B3A
C4A
D2B, C
E3C
F1D, E
