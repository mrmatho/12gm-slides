# High Scoring Command Words

::left::

- State
- Identify
- Name

These are strong, except for when there is especially precise terminology required (i.e. "Hamiltonian path" instead of "path")

::right::

- Calculate
- Determine
- Find

 These are high for routine calculator operations, but low for multi-step financial calculations or scientific notation.

# Data: High scoring question trends

- Identifying Variable types (nominal vs ordinal, continuous vs discrete, categorical vs numerical, explanatory vs response)
- Basic summary statistics: mean, median, mode, range, interquartile range, standard deviation, Upper and lower fences
- Reading graphs and percentage tables
- Predicting and interpreting from a regression line (least squares, not transformed)

layout: center

# Recursion and Financial: High scoring question trends

- Initial values from an amortisation table or loan scenario
- Flat-rate depreciation from rule or recurrence relation
- Definitions and Conversions: Converting between nominal and effective interest rates, Converting between different compounding periods, Converting between different time periods (eg. months to years)

layout: center

# Matrices: High scoring question trends

- Identifying the order of a matrix
- Standard matrix definitions: identify, binary, diagonal, square, permutation, zero, summing
- Matrix operations: addition, subtraction, multiplication, scalar multiplication

layout: center

# Networks and Decisions: High scoring question trends

- Degrees of a vertex
- Using Euler's formula to determine if a graph is planar
- Route identification: Eulerian trails and circuits, Hamiltonian paths and cycles
- Minimum spanning trees: using Prim's algorithm

# Why care about high scoring questions?

- **Low hanging fruit principle:** making sure we get the easy marks
- **Playing the confidence game:** build confidence by getting some easy marks early on
- **Know what you're aiming for:** if a 30 study score is the goal, then nailing all of the questions you find easy gets you a long way
