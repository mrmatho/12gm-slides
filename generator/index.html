Field reference

Shared by Simple Graph, Directed Simple Graph, Flow Network and Bipartite/Matching: labelPosition — "left" (default) / "right" / "above" / "below" draw the node as a small dot with the label as text on that side (on a subtle background for legibility), or "inside" fits the label inside the node itself. dotRadius — dot size outside "inside" mode (default 6). width, height, nodeRadius also apply to all four. Any node object can also set its own labelPosition to override the diagram-level default for just that node (on Bipartite/Matching, this overrides rendering only — column spacing still follows the diagram-level setting, so mixing "inside" into a dot-mode column can overlap neighbours). arrowSize — arrowhead marker width/height for directed edges (default 7); applies to Directed Simple Graph, Flow Network, Activity Network and Forward Scanning Network.

Simple Graph / Directed Simple Graph

nodes: { id, label, x, y }[] — placed by hand, not auto-laid-out.
edges: { from, to, label? }[] — label is optional (e.g. a weight).
directed: defaults false on Simple Graph, true on Directed Simple Graph; an edge can override with its own directed.

Flow Network

nodes: { id, label, x, y }[].
edges: { from, to, capacity }[] — always drawn directed.
cuts: { x1, y1, x2, y2, label?, labelX?, labelY? }[] — dashed line across the diagram.

Bipartite / Matching

leftNodes, rightNodes: { id, label }[] — each stacked into its own column, spacing computed automatically.
edges: { from, to, label? }[] — undirected.
leftLabel, rightLabel: optional column headings.
columnInset: distance from each side to its column (default 70).

Activity Network (AOA)

tasks: { id, duration, predecessors?, dummy? }[] — event nodes, EST/LST and the critical path are all derived from this.
showTimes: default false — event vertices as plain dots; set true for EST|LST split circles.
highlightCriticalPath: default false. nodeRadius (26) applies when showTimes is on, dotRadius (6) when it's off.
width, height: omitted by default — auto-sized from the derived event layout; not in the example JSON for that reason.

Forward Scanning Network (AOA)

Same tasks/derivation as Activity Network, and the same auto-sizing note for width/height, but EST/LST are always shown in two-cell boxes stacked above each event's dot rather than inside the vertex — one box per departing activity (label = that activity's id), or a single unlabelled box for a sink event. Each box's LST is that activity's own latest start (its head event's LST minus its own duration), so activities leaving the same event can show different float.
dotRadius (default 6), boxWidth/boxHeight (default 48 x 20 — box label font size scales with boxHeight automatically). highlightCriticalPath: default false. showValues: default true; set false to export the boxes empty (dividers and activity labels still shown) for students to fill in, or for a blank demo copy.
