Backward Scanning Process

  • Start at the end of the project and work backwards to the start.
  • Travel backwards along the arrows of the network, subtracting the durations from the latest start times.
  • The duration of the project is the latest finish time of the last task(s) in the project.
  • When a task has multiple successors, use the latest start time with the minimum value.
Remember Forward scanning: Earliest Start Time, adding, maximum value. Backward scanning: Latest Start Time, subtracting, minimum value.

The Critical Path

Critical Path
Float Time
  • Tasks that have the same EST and LST cannot be delayed without delaying the whole project. These are called critical tasks.
  • These tasks form the critical path of the project — the longest path through the network, from start to end.
  • There is always at least one critical path in a project network.

Float Time

Float time is the amount of time a task can be delayed without delaying the project:

Float Time = LST − EST

Tasks on the critical path have a float time of 0.

Important Reminders

  • When two arrows meet at a vertex during backward scanning: we take the minimum of the resulting latest start times.
  • You can find the critical path either by forward/backward scanning and identifying the critical (0 float) tasks, or by inspection — finding the longest path through the network.
  • Be careful to follow dummy tasks correctly — they can be part of the critical path even though they have 0 duration.
