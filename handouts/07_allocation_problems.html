Hungarian Algorithm Steps (Recap)

  1. Row reduction: Subtract the value in each row from all entries in that row. Cover the zeros with the minimum number of lines needed. If this equals the number of , go to Step 4.
  2. Column reduction: If fewer lines were needed, subtract the value in each column from all entries in that column. Check the zeros again.
  3. Lowest uncovered number: If still fewer lines than rows, find the in the matrix. Subtract it from all elements, and add it to all elements covered . Repeat until the number of lines equals the number of rows.
  4. Draw the bipartite graph, connecting vertices with edges where the cost is . Use the graph to find the optimal allocation.
  5. Calculate the total cost of the allocation using the matrix (if required).
